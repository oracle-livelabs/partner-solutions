Person Intelligence identifier pop-up — released 30 October 2026

Open Person Intelligence, select a profile, then select its round portrait in
Selected Profile. The portrait is a keyboard-accessible button, including when
the profile uses a fallback image. The native modal restores focus on close.

The top section shows the person reference, name, primary alias, status,
summary, registration date, scoped incident count and dataset. Full person
record expands the narrative and JSON attributes. Below it:

Graph: person-to-identifier relationships, with optional capture/review actors,
type colours, pan, zoom, fit and selectable identifiers or actors. Dashed
identifier outlines mark expired entries; dashed edges mark review. This
network is drawn with D3 from the scoped SQL register response; it does not
create or query a new Oracle SQL property graph.
Table: identifier values, platform/type, validity state, review status, capture
actor/date, reviewer and expiry. Selecting a value shows its complete metadata.
Time: validity Gantt bars or capture/review events. Open validity intervals are
clipped at the chart boundary and marked with arrows, without inventing an end
date in the database. Rows show proposed/expired/current states. Review events
represent administrative review, not independent identity confirmation.

All views share value/actor/source search, identifier-type and validity-state
filters. Selected identifiers retain their detail across tabs. Dates use the
active profile timezone. Source values and attribution are served verbatim.

GET /api/persons/:personRef/identifiers uses SECURE_PERSONS_OF_INTEREST_V and
SECURE_POI_IDENTIFIERS_V with bound references, verifies active profile stability
and returns 404 for inaccessible or unknown people. Requests are cancelled on
close or user/profile changes. More than 1,000 identifiers is explicitly flagged
as a bounded response. No database schema, metadata or identifiers were changed.

Verification: unit checks for scope, SQL binds, profile-change rejection,
empty/large registers, half-open validity, filtering, graph actor grouping and
time domains; browser checks for Graph/Table/Time, selection, filtering,
keyboard tabs, Escape, focus restoration, mobile width 390, fallback portraits,
temporary-error retry, empty registers and stale requests. Live checks covered
all five existing personas and all 17 POIs. No page errors were observed.
