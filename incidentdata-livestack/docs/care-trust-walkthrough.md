Allow about 5–8 minutes, plus AI response time. One question drives this story: **Did private information leave the care team, and what would establish the connection?**

## 1. Something has gone missing

Open **H01 — A missing tool case and a request for support**, then read **Source**.

The original incident describes a missing tool case, entrance damage and a daytime doorbell approach. A new fictional support note adds Resident A's request for help.

Open **H02**. Resident B's report concerns a missing sealed parcel and a caller leaving before entrance damage was found.

Ask: “Two losses, two support requests. Is there anything worth comparing?”

These retain the existing Amsterdam property and entry details. They are not the proposed jewellery-loss or unlocked-door examples.

## 2. A name appears twice

Read **H03**, then **H04**, in Source. Both care-assignment extracts name **Lena Harper**, worker identifier **DEMO-WORKER-17**.

On H03, click **care_worker : DEMO-WORKER-17**. Three sources should appear: **H03, H04 and H06**. This is an exact, namespace-aware match, not an AI guess.

Ask: “The same worker is recorded for both residents. What does that tell us—and what does it not tell us?”

It establishes the recorded assignment, not responsibility for a loss.

Click **Care-Trust: Who knew?** to restore the story.

## 3. The unexpected lead

Read **H05 — A client reference appears in an outward message**.

Resident A's reference appears in an appointment-change extract addressed to an account outside the allocated care team. Private details and usable schedules are withheld.

Then read **H06**: the directory names Lena Harper and outside contact **Morgan Reed**, but directory association does not establish who wrote a message.

Read **H07**: there is limited consent for a transport enquiry concerning **Resident B**. It does not cover Resident A. **H12** explains the extract's provenance gaps.

Ask: “Is this an authorised enquiry, an incomplete record, or a disclosure that needs investigation?”

## 4. Let AI organise the question

Click **Care-Trust: Who knew?** again, then **AI review**. Keep the prepared six-source selection and question.

Click **Draft with Select AI**. Check whether the answer separates care assignment, account attribution, consent and message authorship. Each claim should be checked against its cited source.

One observed wording trap: H05 contains account labels and a client reference, not Lena Harper's name in its verbatim message text. H06 supplies the directory association. Do not present an AI phrase such as “the shared name in the message” as a source finding. Likewise, a person's name and a worker identifier are different fields.

Optionally click **Run native agent review**. Its audit should show **EI_SOURCES_V1** and **EI_CONTEXT_V1**. The agent's review replaces the displayed draft; neither mode changes the case.

Stop with a question, not a guilty-person reveal: “What independent check would clarify the possible disclosure?”
